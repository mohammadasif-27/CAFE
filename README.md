# ☕ CafeHub – Cafe Management System

CafeHub is a Django-based web application designed to manage a cafe online.

## 🚀 Features

- Home page with food items
- Food menu
- Food details and prices
- Staff dashboard
- Add, edit and delete food items
- Contact form
- User accounts

## 🛠️ Technologies Used

- Python
- Django
- HTML
- CSS
- JavaScript
- PostgreSQL

## 💻 Installation

1. Clone the repository:

   git clone https://github.com/mohammadasif-27/CAFE.git

2. Open the project folder:

   cd CAFE

3. Install dependencies:

   pip install -r requirements.txt

4. Run the server:

   python manage.py runserver
